Custom elements are a native browser standard — a class that extends `HTMLElement` and registers under a hyphenated tag name. Once defined, they behave like built-in elements: usable in HTML, React, Vue, or any other context without adapters.

ElementsKit enhances custom elements authoring with signals, JSX, and decorators — but these are optional. You can use the native API alone, then add features gradually as needed.

---

## The native API

No dependencies. The lifecycle is three callbacks:

| Callback | When it fires |
|----------|--------------|
| `connectedCallback` | Element attached to the DOM |
| `disconnectedCallback` | Element removed from the DOM |
| `attributeChangedCallback` | A listed attribute changes |

```ts
class GreetingElement extends HTMLElement {
  connectedCallback() {
    this.textContent = `Hello, ${this.getAttribute("name") ?? "world"}!`;
  }
}

customElements.define("x-greeting", GreetingElement);
```

```html
<x-greeting name="Alice"></x-greeting>
<!-- → Hello, Alice! -->
```

## Adopt ElementsKit progressively

```tsx magic-move
// Step 1 — bare custom element, native API only
class CounterElement extends HTMLElement {
  #count = 0;

  connectedCallback() {
    this.innerHTML = `
      <p>Count: <strong id="val">0</strong></p>
      <button>+1</button>
    `;
    this.querySelector("button")!.addEventListener("click", () => {
      this.#count++;
      this.querySelector("#val")!.textContent = String(this.#count);
    });
  }
}

customElements.define("x-counter", CounterElement);
---
// Step 2 — signal: reactive state, automatic DOM sync
import { signal, effect } from "elements-kit/signals";

class CounterElement extends HTMLElement {
  #count = signal(0);

  connectedCallback() {
    this.innerHTML = `
      <p>Count: <strong id="val"></strong></p>
      <button>+1</button>
    `;
    effect(() => {
      this.querySelector("#val")!.textContent = String(this.#count());
    });
    this.querySelector("button")!.addEventListener("click", () => {
      this.#count(this.#count() + 1);
    });
  }
}
---
// Step 3 — JSX: declarative DOM, live bindings
import { signal } from "elements-kit/signals";

class CounterElement extends HTMLElement {
  #count = signal(0);

  connectedCallback() {
    this.appendChild(
      <section>
        <p>Count: <strong>{this.#count}</strong></p>
        <button onClick={() => this.#count(this.#count() + 1)}>+1</button>
      </section> as Element,
    );
  }
}
---
// Step 4 — @reactive: natural property access + computed
import { computed, reactive } from "elements-kit/signals";

class CounterElement extends HTMLElement {
  @reactive() count = 0;
  doubled = computed(() => this.count * 2);

  connectedCallback() {
    this.appendChild(
      <section>
        <p>
          <strong>{() => this.count}</strong>
          {" × 2 = "}
          <strong>{this.doubled}</strong>
        </p>
        <button onClick={() => this.count++}>+1</button>{" "}
        <button onClick={() => this.count--}>−1</button>
      </section> as Element,
    );
  }
}
---
// Step 5 — @attributes: HTML attributes ↔ reactive properties
import { computed, reactive } from "elements-kit/signals";
import { attributes, ATTRIBUTES as attr } from "elements-kit/attributes";

@attributes
class CounterElement extends HTMLElement {
  static [attr] = {
    count(this: CounterElement, value: string | null) {
      this.count = Number(value ?? 0);
    },
  };

  @reactive() count = 0;
  doubled = computed(() => this.count * 2);

  connectedCallback() {
    this.appendChild(
      <section>
        <p>
          <strong>{() => this.count}</strong>
          {" × 2 = "}
          <strong>{this.doubled}</strong>
        </p>
        <button onClick={() => this.count++}>+1</button>{" "}
        <button onClick={() => this.count--}>−1</button>
      </section> as Element,
    );
  }
}

customElements.define("x-counter", CounterElement);
// <x-counter count="5" />  or  <x-counter count={signal(9)} />
```

| Step | ElementsKit | What you gain |
|------|-------------|---------------|
| 1 | — (plain browser API) | Zero deps, runs anywhere |
| 2 | `elements-kit/signals` — `signal` + `effect` | Reactive state, no manual DOM queries |
| 3 | `elements-kit` JSX runtime | Declarative DOM, live text and attribute bindings |
| 4 | `@reactive` decorator | Natural class-field syntax, derived values with `computed` |
| 5 | `elements-kit/attributes` — `@attributes` | HTML attribute ↔ reactive property wiring |

## Cleanup

Stop effects and timers in `disconnectedCallback`. Use `effectScope` to group everything — one call to `stop()` tears it all down:

```ts
import { reactive, effectScope, onCleanup } from "elements-kit/signals";

class ClockElement extends HTMLElement {
  #time = signal(new Date());
  #stop?: () => void;

  connectedCallback() {
    this.#stop = effectScope(() => {
      const id = setInterval(() => this.#time(new Date()), 1000);
      onCleanup(() => clearInterval(id)); // clears on scope stop
    });

    this.appendChild(
      <time>{() => this.#time().toLocaleTimeString()}</time> as Element,
    );
  }

  disconnectedCallback() {
    this.#stop?.(); // stops interval + all effects in scope
  }
}
```
