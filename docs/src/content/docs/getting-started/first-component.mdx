Build a reactive counter to see signals, JSX, and class components working together. Under twenty lines of code, no framework, no build-step magic — just standard browser APIs with reactive glue.

## The counter

```tsx twoslash
// @noErrors
import { computed, reactive } from "elements-kit/signals";
import { render } from "elements-kit/render";

class Counter {
  @reactive() count = 0;
  doubled = computed(() => this.count * 2);

  render() {
    return (
      <section>
        <p>
          <strong>{() => this.count}</strong> × 2 = <strong>{this.doubled}</strong>
        </p>
        <button onClick={() => this.count++}>+1</button>{" "}
        <button onClick={() => this.count--}>−1</button>
      </section>
    ) as Element;
  }
}

const unmount = render(
  document.getElementById("app")!,
  () => new Counter().render(),
);
```

Mount it into any page container:

```html
<div id="app"></div>
```

## What's happening

- **`@reactive() count = 0`** — makes `this.count` a reactive signal. Reads subscribe, writes notify.
- **`computed(() => this.count * 2)`** — derived value, recomputed only when `count` changes.
- **`{() => this.count}`** — the `() =>` wrapper creates a live text node that updates in place.
- **`render(target, setup)`** — runs `setup` inside an [`effectScope`](/scopes), appends the returned node to `target`, and hands back a single `unmount` thunk that removes the node and tears down every effect inside.
- **No framework runtime** — `Counter` is a plain class. JSX compiles to real `document.createElement` calls.
