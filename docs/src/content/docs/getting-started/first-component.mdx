Build a reactive counter to see signals, JSX, and custom elements working together. Ten lines of code, no framework, no build-step magic — just standard browser APIs with reactive glue.

## The counter

```tsx
import { computed, reactive } from "elements-kit/signals";
import { attributes, ATTRIBUTES as attr } from "elements-kit/attributes";
import { render } from "elements-kit/render";

@attributes
class CounterElement extends HTMLElement {
  static [attr] = {
    count(this: CounterElement, value: string | null) {
      this.count = Number(value ?? 0);
    },
  };

  @reactive() count = 0;
  doubled = computed(() => this.count * 2);

  #unmount?: () => void;

  connectedCallback() {
    this.#unmount = render(this, () => (
      <section>
        <p>
          <strong>{() => this.count}</strong> × 2 = <strong>{this.doubled}</strong>
        </p>
        <button onClick={() => this.count++}>+1</button>{" "}
        <button onClick={() => this.count--}>−1</button>
      </section>
    ) as Element);
  }

  disconnectedCallback() {
    this.#unmount?.();
    this.#unmount = undefined;
  }
}

customElements.define("x-counter", CounterElement);
```

Use it like any built-in HTML element:

```html
<x-counter count="5"></x-counter>
```

## What's happening

- **`@reactive() count = 0`** — makes `this.count` a reactive signal. Reads subscribe, writes notify.
- **`computed(() => this.count * 2)`** — derived value, recomputed only when `count` changes.
- **`{() => this.count}`** — the `() =>` wrapper creates a live text node that updates in place.
- **`@attributes` + static `[attr]`** — wires the `count` HTML attribute to the reactive property.
- **No framework runtime** — `CounterElement` is a plain `HTMLElement` usable in React, Vue, or raw HTML.
