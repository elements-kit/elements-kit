---
title: Async Utility
---


The `async` utility in ElementsKit is a **promise factory and controller**. It lets you create, control, and observe the lifecycle of promises in a reactive way. You can start, stop, and rerun async operations, and track their state, value, and errors with fine-grained reactivity.

It provides a reactive, signal-based wrapper for asynchronous operations. It enables you to manage loading, error, and result states in a fine-grained, composable way.

## Basic Usage

```ts
import { async } from "elements-kit/utilities/async";

const fetchItems = async(() => fetch("/api/items").then((res) => res.json()));

fetchItems.run();
```

## Reactive State Properties

`Async` exposes reactive state properties mirroring a promise, which update automatically:

```ts
fetchItems.state;  // "pending" | "fulfilled" | "rejected"
fetchItems.value;  // resolved value (if fulfilled)
fetchItems.reason; // error (if rejected)
fetchItems.result; // value or error
fetchItems.pending; // true if pending
```

These properties are tracked and can be used in effects or templates.

## Awaitable

You can `await` an `Async` instance directly, or after calling `run()`:

```ts
const op = async(() => Promise.resolve(123));
op.start();
const value = await op; // 123

// Or run with arguments and await
const mutation = async((id: number) =>
  fetch(`/api/todos/${id}`, { method: "DELETE" }).then((r) => r.json()),
);
const result = await mutation.run(42); // await result of mutation
```

This works because `Async` implements `.then`, `.catch`, and `.finally`.

## Cache Pattern

```ts
import { async } from "elements-kit/utilities/async";
import { storage } from "elements-kit/utilities/storage";

const cache = storage("todos"); // persists across reloads
const query = async(() =>
  fetch("/api/todos")
    .then((r) => r.json())
    .then(cache), // cache is passed through and also saved to storage
).start(); // query.value updates reactively; cache persists across reloads
```

## Mutation Pattern

```ts
const mutation = async((id: number) =>
  fetch(`/api/todos/${id}`, { method: "DELETE" }).then(res => res.json())
);

const result = await mutation.run(123); // fire once, await result
```

## oncleanup Example

Register cleanup logic inside your async function (e.g., for aborting fetches):

```ts
import { oncleanup } from "elements-kit/signals";

const query = async((id: number) => {
  const controller = new AbortController();
  oncleanup(() => controller.abort()); // runs when stop() is called or effect re-runs
  return fetch(`/api/todos/${id}`, { signal: controller.signal }).then((r) =>
    r.json(),
  );
}).start();
```

## Using Parameters

You can define an async operation that takes an input parameter. The input type is inferred from your function signature:

```ts
import { async } from "elements-kit/utilities/async";

const fetchTodo = async((id: number) => {
  return fetch(`https://jsonplaceholder.typicode.com/todos/${id}`)
    .then(res => {
      if (!res.ok) throw new Error("Not OK");
      return res.json();
    });
});

fetchTodo.run(1);
```

## Reactive Reruns

Pass a signal value into `run()` inside an `effect` to automatically re-fetch when it changes:

```ts
import { signal, effect } from "elements-kit/signals";

const todoId = signal(1);

effect(() => {
  fetchTodo.run(todoId()); // re-fetches when todoId changes
});
```

Or read the signal directly inside the async function:

```ts
import { async } from "elements-kit/utilities/async";
import { signal } from "elements-kit/signals";

const id = signal(1);

const fetchTodo = async(() => {
  return fetch(`https://jsonplaceholder.typicode.com/todos/${id()}`)
    .then(res => {
      if (!res.ok) throw new Error("Not OK");
      return res.json();
    });
}).start(); // re-fetches automatically when id changes
```

:::caution[Signals aren't tracked after an `await`]
Signals are only tracked up to the first `await` in your async function. Read all reactive values before the first `await` if you want reruns on change.

```ts
const id = signal(1);

// ❌ Not reactive — id() is read after an await
const op = async(async function () {
  await someAsyncSetup();
  const currentId = id(); // not tracked
});

// ✅ Reactive — id() is read before any await
const op = async(async function () {
  const currentId = id(); // tracked
  await fetch(`/todos/${currentId}`);
});
```
:::

## Rerun with Clean

```ts
op.start() // start auto-reruns on signals or fn changes and run cleanup logic on change.
op.stop(); // Stop auto-reruns, and run cleanup logic
op.run();  // run cleanup logic, and run once
```
