Components are classes with a `render()` method. JSX compiles through ElementsKit's jsx-runtime, producing real DOM elements — no virtual DOM.

## Class components

```tsx
class Greeting {
  name = "world";

  render() {
    return <h1>Hello, {this.name}!</h1> as Element;
  }
}

document.body.appendChild(new Greeting().render());
```

## Reactive props

| Syntax | Description |
| --- | --- |
| `{signal}` | Live-bound reactive child |
| `on:click={fn}` | Event listener |
| `class:active={bool}` | Toggle a CSS class |
| `style:color={value}` | Reactive inline style |

## Building a Counter

Step through the construction of a reactive Counter — from a bare signal to a full component.

export const STEPS = [
  `const count = signal(0);`,
  `const count = signal(0);
const doubled = computed(() => count() * 2);`,
  `class Counter {
  count = signal(0);
  doubled = computed(() => this.count() * 2);

  render() {
    return (
      <div>
        <p>Count: {this.count}</p>
        <p>Doubled: {this.doubled}</p>
      </div>
    );
  }
}`,
  `class Counter {
  @reactive() count = 0;
  doubled = computed(() => this.count * 2);

  render() {
    return (
      <div>
        <p>Count: {() => this.count}</p>
        <p>Doubled: {this.doubled}</p>
        <button on:click={() => this.count++}>+1</button>
      </div>
    );
  }
}`,
  `class Counter {
  @reactive() count = 0;
  doubled = computed(() => this.count * 2);

  render() {
    return (
      <div>
        <p>Count: {() => this.count} — Doubled: {this.doubled}</p>
        <button on:click={() => this.count++}>+1</button>
        <button on:click={() => this.count--}>−1</button>
        <button on:click={() => (this.count = 0)}>Reset</button>
      </div>
    );
  }
}`,
];
