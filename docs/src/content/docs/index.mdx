## How it works

ElementsKit has three core building blocks:

- **Signals** — reactive values that automatically track dependencies
- **JSX elements** — build DOM trees with standard JSX syntax, no plugin required
- **Custom Elements** — Helper functions and decorators for building reactive web components

```tsx {3-3} "count"
import { signal } from "elements-kit/signals";

const count = signal(0);

document.body.appendChild(
  (
    <button on:click={() => count(count() + 1)}>Count: {count}</button>
  ) as Element,
);
```
