ElementsKit is a set of **universal reactive primitives** for building web UI. It works standalone, inside React or Vue, or as the foundation of your own component model — no framework required, no virtual DOM.

<CardGrid>
  <Card title="Signals" icon="rocket">
    Fine-grained reactive state. `signal`, `computed`, `effect`, stores, and utilities like `createMediaQuery` — framework-agnostic, usable anywhere JS runs.
  </Card>
  <Card title="Elements" icon="puzzle">
    JSX compiles to real `document.createElement` calls. Reactive props become live DOM bindings — no diffing, no reconciliation, no runtime overhead.
  </Card>
  <Card title="Custom Elements" icon="setting">
    Native `HTMLElement` subclasses enhanced with signals, JSX, and decorators. Usable in any HTML context — React, Vue, or plain HTML — no adapters needed.
  </Card>
  <Card title="Integrations" icon="external">
    Connect signals and stores to React via `useSignal` and `useScope`. More framework integrations planned — Vue, Solid, and beyond.
  </Card>
</CardGrid>

If you are using JSX to build elements or custom elements, configure your `tsconfig.json` to point to the ElementsKit JSX runtime:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "elements-kit"
  }
}
```

Then use it in a component:

```tsx
import { signal, computed, reactive } from "elements-kit/signals";
import { attributes, ATTRIBUTES as attr } from "elements-kit/attributes";

@attributes
class CounterElement extends HTMLElement {
  static [attr] = {
    count(this: CounterElement, value: string | null) {
      this.count = Number(value ?? 0);
    },
  };

  @reactive() count = 0;
  doubled = computed(() => this.count * 2);

  connectedCallback() {
    this.appendChild(
      <section>
        <p>
          <strong>{() => this.count}</strong> × 2 = <strong>{this.doubled}</strong>
        </p>
        <button onClick={() => this.count++}>+1</button>{" "}
        <button onClick={() => this.count--}>−1</button>
      </section> as Element,
    );
  }
}

customElements.define("x-counter", CounterElement);
```

```html
<!-- Works in any HTML file, no build step for consumers -->
<x-counter count="5"></x-counter>
```

## How it fits together

The pieces are independent and composable — not a strict hierarchy. Signals are the shared language that connects everything.

<Diagram code={`flowchart TB
    S["signals
    signal · computed · effect · @reactive · stores"]

    E["elements  JSX → DOM
    div · {signal} · on:click · style:color"]

    CE["custom elements
    HTMLElement · @attributes · Slot / Slots"]

    FW["framework integrations
    useSignal · useScope"]

    S -->|"powers live bindings"| E
    S -->|"powers @reactive / computed"| CE
    E -.->|"JSX renders CE internals"| CE
    CE -->|"native HTML tag"| FW
    S -->|"useSignal / useScope"| FW`} />

- **Signals** power live DOM bindings in JSX and reactive properties in custom elements. They can also be subscribed to directly from any framework.
- **Elements** are a pattern built on top of signals and JSX. the result is a reactive DOM.
- **Custom elements** are a native browser standard. React, Vue, and plain HTML can all use `<x-counter />` as a regular HTML tag — no adapter, no wrapper.
- **Framework integrations** get both sides: shared signal state via `useSignal`/`useScope`, and any custom element as a native HTML tag.

## Which pattern should I use?

| Pattern | When to use it |
|---------|---------------|
| **Plain signals** | Pure logic, no UI. Node.js scripts, workers, utilities that need reactive state. |
| **Elements / JSX** | Inline reactive UI in scripts. Quick components appended directly to the DOM. |
| **Components** | Class-based UI with `render()`. Share state across multiple elements via stores. |
| **Custom elements** | Reusable across frameworks. Native HTML integration, Shadow DOM, framework-agnostic distribution. |

Start with the simplest option that fits your needs — you can always combine patterns:

```tsx
// Just need reactive state? Use signals standalone
const count = signal(0);

// Building UI? Add JSX for declarative DOM
document.body.appendChild(<button onClick={() => count(count() + 1)}>{count}</button> as Element);

// Need reusable components? Add class components
class Counter { @reactive() count = 0; render() { return <button onClick={() => this.count++}>{this.count}</button>; } }

// Sharing across pages/frameworks? Package as custom elements
@attributes class MyElement extends HTMLElement { ... }
```
