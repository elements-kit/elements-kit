A native `<button>` element styled via class + data attributes from the optional [styles layer](/ui/styles). Six variants, four sizes, accent-color theming, high-contrast and disabled states — all driven by data attributes on a single `.x-button` class.

## Install

```ts
import "elements-kit/ui/styles/base.css";
import "elements-kit/ui/styles/scaling.css";
import "elements-kit/ui/styles/radius.css";
import "elements-kit/ui/styles/space.css";
import "elements-kit/ui/styles/shadow.css";
import "elements-kit/ui/styles/typography.css";
import "elements-kit/ui/styles/cursor.css";
// import any color scales you want to use for accent theming:
import "elements-kit/ui/styles/colors/mint.css";
import "elements-kit/ui/styles/accent/mint.css";
// import any gray scales you want to use for neutral theming:
import "elements-kit/ui/styles/colors/slate.css";
import "elements-kit/ui/styles/gray/slate.css";
// and of course the button itself:
import "elements-kit/ui/button/button.css";
```

See [Styles](/ui/styles) for the full token system, accent/gray scale lists, and theming knobs.

## API

```html
<button
  class="x-button"
  data-variant="solid"
  data-size="2"
  data-accent-color="mint"
>
  Click me
</button>
```

| Attribute | Values |
| --- | --- |
| `data-variant` | `classic`, `solid`, `soft`, `surface`, `outline`, `ghost` |
| `data-size` | `1`, `2`, `3`, `4` |
| `data-accent-color` | any imported color scale (`mint`, `blue`, `iris`, …) |
| `data-high-contrast` | modifier — boosts contrast against the page background |
| `data-loading` | modifier — sets `position: relative` for a spinner overlay |
| `disabled` / `data-disabled` | native `:disabled` state, or `data-disabled` on non-button elements |

## Sizing

Each size maps to a height token from the [space scale](/ui/styles#spacing):

| `data-size` | height | radius |
| --- | --- | --- |
| `1` | `--space-5` (24px) | `max(--radius-1, --radius-full)` |
| `2` | `--space-6` (32px) | `max(--radius-2, --radius-full)` |
| `3` | `--space-7` (40px) | `max(--radius-3, --radius-full)` |
| `4` | `--space-8` (48px) | `max(--radius-4, --radius-full)` |

The radius respects `data-radius` on a parent — set `data-radius="full"` on the page root for pill buttons everywhere.

## Variants

- **`classic`** — raised, with subtle inner shadow. Default for primary actions.
- **`solid`** — flat, accent-colored fill. Confident primary action.
- **`soft`** — tinted, low-emphasis background. Pairs well with surfaces.
- **`surface`** — outlined panel with subtle fill. Borderline calls-to-action.
- **`outline`** — bordered, transparent fill. Tertiary actions.
- **`ghost`** — no background, no border. Toolbar-style.

## Theming

Switch the accent on a single button with `data-accent-color="<color>"`, or set it on any ancestor (e.g. `<body>`) to theme the whole subtree.

```html
<body data-accent-color="iris" data-radius="large">
  <button class="x-button" data-variant="solid" data-size="3">
    Themed primary
  </button>
</body>
```

Light/dark flips automatically via the `.dark` class on a parent — see [Light & dark](/ui/styles#light--dark).
