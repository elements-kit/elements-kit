## Install

```ts
import "elements-kit/ui/styles/theme.css";
import "elements-kit/ui/styles/scaling.css";
import "elements-kit/ui/styles/radius.css";
import "elements-kit/ui/styles/space.css";
import "elements-kit/ui/styles/shadow.css";
import "elements-kit/ui/styles/typography.css";
import "elements-kit/ui/styles/cursor.css";
import "elements-kit/ui/styles/unset.css";
// import any color scales you want to use for color theming:
import "elements-kit/ui/styles/palette/mint.css";
import "elements-kit/ui/styles/colors/mint.css";
// import any gray scales you want to use for neutral theming:
import "elements-kit/ui/styles/palette/slate.css";
import "elements-kit/ui/styles/base/slate.css";
// and of course the button itself:
import "elements-kit/ui/button/button.css";
```

See [Styles](/ui/styles) for the full token system, accent/gray scale lists, and theming knobs.

## API

```html
<button
  class="unset x-button"
  data-variant="solid"
  data-size="2"
  data-color="mint"
>
  Click me
</button>
```

The `unset` class ([Styles → Unset native styles](/ui/styles#unset-native-styles)) clears the browser's default `<button>` rendering so `.x-button` styles render predictably. Skip it and you'll see leaked native styling (gray background, system font, beveled border).

| Attribute | Values |
| --- | --- |
| `data-variant` | `classic`, `solid`, `soft`, `surface`, `outline`, `ghost` |
| `data-size` | `1`, `2`, `3`, `4` |
| `data-color` | any imported color scale (`mint`, `blue`, `iris`, …) |
| `data-high-contrast` | modifier — boosts contrast against the page background |
| `data-loading` | modifier — sets `position: relative` for a spinner overlay |
| `disabled` / `data-disabled` | native `:disabled` state, or `data-disabled` on non-button elements |

## Sizing

Each size maps to a height token from the [space scale](/ui/styles#spacing):

| `data-size` | height | radius |
| --- | --- | --- |
| `1` | `--space-5` (24px) | `max(--radius-1, --radius-full)` |
| `2` | `--space-6` (32px) | `max(--radius-2, --radius-full)` |
| `3` | `--space-7` (40px) | `max(--radius-3, --radius-full)` |
| `4` | `--space-8` (48px) | `max(--radius-4, --radius-full)` |

The radius respects `data-radius` on a parent — set `data-radius="full"` on the page root for pill buttons everywhere.

## Variants

- **`classic`** — raised, with subtle inner shadow. Default for primary actions.
- **`solid`** — flat, color-driven fill. Confident primary action.
- **`soft`** — tinted, low-emphasis background. Pairs well with surfaces.
- **`surface`** — outlined panel with subtle fill. Borderline calls-to-action.
- **`outline`** — bordered, transparent fill. Tertiary actions.
- **`ghost`** — no background, no border. Toolbar-style.

## Use as a link

`.x-button` is class-only — apply it to any element you want shaped like a button. The most common case is a link that should look like a button:

```html
<a
  class="unset x-button"
  data-variant="solid"
  data-size="2"
  href="/getting-started/installation"
>
  Get started
</a>
```

`unset` zeroes the anchor's default underline and color so the `.x-button` styles render exactly like on a `<button>`. Native semantics (focus, navigation, right-click → open in new tab) are preserved — pick `<a>` when the action navigates and `<button>` when it triggers a JS handler.

## Radius

Set `data-radius="<value>"` on a parent (e.g. `<body>`) to control corner radius for every button beneath. Values follow [Styles → Radius](/ui/styles#radius):

```html
<div data-radius="full">
  <button class="unset x-button" data-variant="solid">Pill</button>
</div>
<div data-radius="none">
  <button class="unset x-button" data-variant="solid">Square</button>
</div>
```

| `data-radius` | Effect |
| --- | --- |
| `none` | square corners — `--radius-factor: 0` |
| `small` | tighter — `--radius-factor: 0.75` |
| `medium` | default |
| `large` | softer — `--radius-factor: 1.5` |
| `full` | fully rounded — `--radius-full: 9999px` |

The size's own radius is `max(--radius-N, --radius-full)`, so `data-radius="full"` always wins regardless of size.

## Theming

Switch the color on a single button with `data-color="<color>"`, or set it on any ancestor (e.g. `<body>`) to theme the whole subtree.

```html
<body data-color="iris" data-radius="large">
  <button class="unset x-button" data-variant="solid" data-size="3">
    Themed primary
  </button>
</body>
```

Light/dark flips automatically via the `.dark` class on a parent — see [Light & dark](/ui/styles#light--dark).
